---
name: write-adr
description: Cria um Architecture Decision Record para uma decisão técnica relevante do Tuprel.
disable-model-invocation: true
allowed-tools: Read Grep Glob
---

Prepara um ADR para `$ARGUMENTS` usando a estrutura:

- Contexto
- Problema
- Restrições
- Opções consideradas
- Decisão
- Consequências positivas
- Consequências negativas
- Riscos
- Alternativas rejeitadas
- Impacto em compatibilidade
- Impacto em segurança
- Como validar a decisão

Não inventes consenso. Se houver informação insuficiente, apresenta as opções e marca a decisão como `Proposta`.
