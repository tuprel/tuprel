# ADR-0004-schema-first-codegen: Schema validado e code generation type-safe

Estado: Aceite

## Contexto e decisão

`schema.jorvia` produz um modelo validado que alimenta geração de Java. O developer não precisa manter manualmente entidade + repository + metadata redundantes para cada model.

## Consequências

Esta decisão deve ser reflectida na implementação, testes e documentação. Alterações significativas exigem novo ADR que substitua explicitamente este quando aplicável.
